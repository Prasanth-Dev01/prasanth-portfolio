# Prasanth — Frontend Developer Portfolio

A responsive, dark editorial-style portfolio built with Next.js App Router, TypeScript, Tailwind CSS v4, GSAP, and Lucide React. The site uses Server Components by default; the navigation, contact action, and animation layer opt into client rendering where needed.

## Requirements

- Bun 1.1 or newer
- Node.js 20 or newer

## Run locally

```bash
bun install
bun run dev
```

## Checks

```bash
bun run lint
bun run typecheck
bun run build
```
